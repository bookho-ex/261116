1. 두 목록의 출력이 서로 다른 이유

.textContent 속성은 텍스트만 화면에 표시할 수 있어서 문자열이 아닌 데이터를 대입하면 자바스크립트가 내부적으로
.toString()을 호출해 강제로 문자열로 바꾼다


(1) 객체를 그대로 넣은 줄

li1.textContent = items[i]; 코드에서 items[i]는 여러 데이터를 묶어놓은 개체 자체이기에 자바스크립트가 내부의 이름, 메시지 등을
나열하지 않고 Object 타입의 객체라는 뜻의 기본 물자열인 object Object를 반환한다


(2) 점 표기로 꺼내 넣은 줄

items[i].name 처럼 객체 내부에서 꺼낸 값들은 이미 문자열 데이터이기에 변환 과정 없이 원래의 글자가 그대로 화면에 출력된다


2. 객체에서 필요한 값을 꺼내 화면에 표시하는 법

객체는 여러 정보를 담고있기에 화면에 표시하려면 객체 그 자체를 통째로 넣지 말고 지정하여 알맹이만 꺼낸 뒤 문자열로 조합해야한다


(1) 점 표기법

객체.속성명 형태로 마침표를 찍어 원하는 값에 직접 접근한다

li2.textContent = `${items[i].name}: ${items[i].message} (${items[i].date})`;

items[i].name - 객체 안에 있는 name 값(하늘, 바다)을 꺼낸다
items[i].message - 객체 안에 있는 message 값(안녕하세요, 잘 봤습니다)을 꺼낸다
items[i].date - 객체 안에 있는 date 값(2026. 11. 16.)을 꺼낸다
